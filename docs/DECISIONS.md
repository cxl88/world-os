# 架构决策记录

每条决策：背景 → 决定 → 代价。新决策追加在末尾，不改旧条目；推翻旧决策时新写一条并注明。

## ADR-001 只用 Python 标准库 + SQLite（2026-10-23）

- 背景：个人使用、Windows 优先、预算接近 0、维护时间每周不超过 1 小时。
- 决定：不引入任何第三方依赖；数据存单个 SQLite 文件；界面是命令行 + Markdown 导出。
- 代价：没有图形界面；RSS 解析只支持常见格式；HTTP 调用自己写（约 40 行）。

## ADR-002 一个模型、一个提取任务，不做多智能体（2026-10-23）

- 背景：任务书要求“不要为了使用 AI Agent 而设计 AI Agent”。
- 决定：模型只做一件事：从信息条目中提取候选机会卡。评分、简报、状态流转全部由确定性程序完成。
- 代价：模型不能帮你评分；这是有意的，评分需要可解释并由人负责。

## ADR-003 模型适配只走 OpenAI 兼容接口，未配置时降级为手动模式（2026-10-23）

- 背景：不依赖单一收费模型；国内可用性和支付方式不确定。
- 决定：`llm.py` 只实现 OpenAI 兼容的 `/chat/completions`；没有配置、配置不全或调用失败时，生成提示词文件让你粘贴到已有聊天工具。另有确定性模拟适配器仅供测试。
- 代价：不用厂商专有功能（如结构化输出、工具调用），JSON 由程序校验。

## ADR-004 证据强度、支付意愿、成交状态三者分开（2026-10-23，架构审查 001 任务四）

- 背景：原 E0–E3 把“证据等级”和“成交进度”混在一起，单条证据就能把机会推到高分。
- 决定：8 类证据；按独立来源计算强度；支付意愿只认客户类证据；成交状态单独从日志计算。详见 docs/SCORING.md。
- 代价：规则更多，需要文档和测试同步维护。

## ADR-005 AI 输出一律是“候选数据”（2026-10-23）

- 背景：外部资料可能含提示词注入，模型输出可能越权。
- 决定：外部文本包在 `<item>` 数据区并中和伪造标签；模型输出按白名单字段导入，证据只能引用本批条目，链接取原始条目；AI 卡待审核、AI 证据未核实；整批事务导入。
- 代价：模型输出里的任何额外信息都会被丢弃（会给出警告）。

## ADR-006 数据目录统一（2026-10-23）

- 背景：原型默认把数据库建在当前目录，Windows 上换个目录运行就像“数据丢了”。
- 决定：`--db` > `WORLDOS_DB` > `WORLDOS_HOME` > `~/worldos-data`；提示词、简报、备份、导出都在数据目录下。
- 代价：与 v0.1 原型的默认位置不兼容；v0.1 数据库结构版本不同，会被拒绝打开并提示。

## ADR-007 真实数据不进仓库（2026-10-23，架构指令 002）

- 决定：`.gitignore` 排除数据库、数据目录、profile.md、本地配置。仓库只放源码、测试、文档、合成演示数据和带出处的公开信息样本。

## ADR-008 预算闸门按单次上限预留，用量未知按上限记账（2026-10-23，架构审查 002）

- 背景：原闸门只在“已花 ≥ 预算”时拦截，最后一次请求可以整笔超支；供应商没有返回用量时记成 0。
- 决定：请求前按输入 UTF-8 字节数（字节级分词每个 token 至少 1 字节）加 64 个 token 的格式开销、输出按 `max_tokens` 估算单次上限，“已计 + 上限 > 预算”就拦截；请求前先写一条 pending 并按上限计入；用量缺失、调用失败、程序中断都按上限计入并标“待对账”；单价、预算、次数必须是有限的非负数。数据库结构升到版本 3，版本 2 打开时自动升级。
- 代价：中文输入会被高估 2–4 倍，预算会比实际更早用完；仍然只是本地闸门，依赖供应商遵守 `max_tokens`，不能替代供应商后台的消费上限。

## ADR-009 开发冻结（2026-10-23，架构指令 003；PR #13 合并后生效）

- 背景：系统已经能支撑真实验证，继续加功能只会推迟接触真实客户。
- 决定：PR #13 合并后暂缓新增产品模块。只有以下三种情况可以改代码：
  1. 发现阻碍真实使用的缺陷；
  2. 出现数据安全或成本风险；
  3. 商业验证（如 Experiment 001）暴露了必须修复的核心问题。

  文档、验收材料、实验记录不受限制。不开发复杂前端、额外 Agent、移动端或大规模数据采集。每个 PR 在模板里写明属于哪一种情况，说不清的不合并。
- 代价：已知的非阻塞局限（KNOWN_ISSUES 的 L 项）暂时不处理。
